# VitaJS documentation

The files in this directory contain focused usage examples for individual VitaJS APIs.

| Guide | What it covers |
| --- | --- |
| [quick-start.md](quick-start.md) | Minimal app and frame loop |
| [screen.md](screen.md) | Drawing, colors and textures |
| [pads.md](pads.md) | Buttons, analog sticks and controller ports |
| [touch.md](touch.md) | Front/rear touch input, panel info and sampling |
| [font.md](font.md) | Font loading, drawing and metrics |
| [audio.md](audio.md) | WAV sound effects and WAV/OGG streamed audio |
| [net.md](net.md) | Synchronous HTTP |
| [system.md](system.md) | Filesystem, app manifest, language and hardware info |
| [app.md](app.md) | App lifecycle and system events |
| [dialog.md](dialog.md) | Native message and keyboard dialogs |
| [power.md](power.md) | Battery, clocks and power state |
| [timers.md](timers.md) | Timers and the main game loop |

For signatures and available constants, see [`../src/assets/vitajs.d.ts`](../src/assets/vitajs.d.ts).

VitaJS is experimental. Some Vita system APIs are only partially implemented by Vita3K, so hardware-facing APIs should also be validated on a physical PS Vita.
